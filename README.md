# ZX-Spectrum 48K Issue 3B - Based on Gerbers by PABB on PCBWay

KiCAD created files for the ZX Spectrum 48K Issue 3B designed by Sinclair Research Ltd - Based on PABB Gerbers

Original Gerbers by PABB downloadable via PCBWay.

See https://www.pcbway.com/project/shareproject/ZX_Spectrum_48_Issue_3B_Redrawn.html

Only the gerbers are available on PCBWay. No Schematic.

Schematic created from available schematics with corrections using Service Guide mods and PCB layout. 

Where differences were seen the PCB layout took preference.

This was only done in order to create an assist in debugging.

I would NOT use these gerbers to get a PCB manufactured without a lot more checking first.

For the following ULA 6C001 make the following changes,

R47 to 1K,
R49 to 10K,
R56 to 1K,
R63 to 1K.
